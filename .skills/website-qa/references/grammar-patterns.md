# Grammar & Spelling Patterns Reference

## High-Frequency Web Copy Mistakes

### Homophones & Confusables
| Wrong | Right | Context |
|---|---|---|
| It's features | Its features | Possessive = no apostrophe |
| Your welcome | You're welcome | "You are welcome" |
| Their coming | They're coming | "They are coming" |
| Effect vs affect | Affect = verb, Effect = noun | "It affects X" / "The effect is Y" |
| Principal vs principle | Principal = main/person; Principle = rule | |
| Stationary vs stationery | Stationary = not moving; Stationery = paper | |
| Complement vs compliment | Complement = completes; Compliment = praise | |
| Discreet vs discrete | Discreet = tactful; Discrete = separate | |
| Fewer vs less | Fewer = countable; Less = uncountable | "Fewer clicks, less time" |
| Which vs that | That = restrictive clause; Which = non-restrictive | |

### Business/Marketing Copy Patterns
- "We're" vs "were" — common typo in button copy
- "Setup" (noun) vs "set up" (verb) — "Follow the setup" / "Set up your account"
- "Login" (noun) vs "log in" (verb) — "Go to the login page" / "Log in here"
- "Email" not "e-mail" (modern standard)
- "Website" not "web site" (modern standard)
- "Startup" not "start-up" (modern standard)
- "Username" not "user name"

### Capitalisation Issues
- Product feature names: decide and apply consistently (e.g., "Dashboard" vs "dashboard")
- Job titles: only capitalise when before a name ("Chief Executive Jane" vs "the chief executive")
- Seasons: not capitalised ("this spring", not "this Spring")
- Directions: only capitalised as proper nouns ("the North" as region vs "drive north")

### Punctuation in UI
- Buttons: no period at end of button label
- Error messages: end with a period
- Tooltips: end with a period
- Placeholder text in inputs: no period, starts lowercase typically
- Navigation items: no period, title case or sentence case (pick one)

### Number Formatting
- Numbers 1–9: typically spelled out in body copy ("three options", not "3 options")
- Numbers 10+: use numerals ("15 features")
- Percentages: "50%" in data, "50 percent" in prose (be consistent)
- Currency: "$50" not "50 dollars" in UI; be consistent with decimal places
- Phone numbers: consistent format (+1 (555) 000-0000 or +15550000000)

### Common Tech/SaaS Copy Issues
- "It's easy to use" — vague; flag for content improvement
- "Best-in-class" — vague superlative with no proof
- Passive voice overuse — "is designed to help" → "helps"
- "Leveraging synergies" — jargon; flag
- "Simply" / "just" — can feel dismissive to struggling users
- "Obviously" — condescending

## Style Consistency Checklist
When reviewing a page, note on first occurrence:
1. British or American English? (honour/honor, optimise/optimize)
2. Oxford comma used or not?
3. Heading case: Title Case or Sentence case?
4. Em dash with or without spaces? (word—word vs word — word)
5. Ampersand (&) or "and" in headings?
